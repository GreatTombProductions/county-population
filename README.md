# County Population Trends

Population estimates and components of change for all 3,144 U.S. counties, 2020–2025. See which counties are growing, shrinking, and why.

**Live site:** https://GreatTombProductions.github.io/county-population/

## What this does

Search any U.S. county to see:
- 2025 population estimate
- Percent change from 2020–2025
- Components of change: births, deaths, net migration
- Year-by-year trend (2020–2025)
- State browse with county rankings

3,144 counties and county equivalents. Data from the U.S. Census Bureau Population Estimates Program.

## Data source

U.S. Census Bureau — Population Estimates Program, 2020–2025 vintage. Published March 2026. Estimates as of July 1 each year.
